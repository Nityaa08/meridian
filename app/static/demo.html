      §1How it works

      Five stages in an asyncio pipeline. The sub-questions are searched concurrently with asyncio.gather, so one slow or failing source cannot stop the run; each stage pushes events to a queue that the HTTP response streams out.

      • Concurrent searchSub-questions run in parallel; a failing source returns nothing instead of failing the run.
      • Ranked evidencePassages are embedded with the question and kept above a similarity threshold.
      • Checked citationsThe report may only cite retrieved URLs; anything else is removed and counted.
      • Honest statusA run that fell back anywhere ends degraded with the reasons listed.

      §2Appendix: stream it yourself

      The page reads the same endpoint. Public use is limited to a few questions an hour per visitor.
